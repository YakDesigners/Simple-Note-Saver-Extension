# Simple Note Saver Extension

## **Effortlessly save, manage, and edit your notes directly within your browser.**

This extension allows you to create, view, and modify notes with ease. Enjoy a seamless experience with features like quick note saving, a convenient search function, and the ability to view and edit your notes in an expanded window for better readability and editing. Ideal for users looking for a simple and effective note management tool.

---

❗ **Important** ❗  
- If your previously saved notes from **Version 1.1** do not appear after updating to the new version, you can manually import them via the **Settings Page**.  
- If note saving is not working correctly, please try **clearing all notes** from the settings or **reinstalling the extension**.

---

## 🔄 **Improvements in Version 2.1**

1. **Enhanced User Interface**:  
   - Improved visual design with cleaner and more intuitive layouts.  
   - Added hover effects for better user experience.

2. **Pinned Notes Feature**:  
   - Introduced the ability to pin important notes, keeping them at the top for quick access.

3. **Dark Mode Support**:  
   - Added a toggle for dark mode to improve usability during nighttime or low-light conditions.

4. **Expanded Note View**:  
   - Enabled users to view and edit notes in a larger, separate window for better readability and advanced editing.

5. **Link Highlighting**:  
   - Automatically detects and highlights links in notes, making them clickable for easy access.

6. **Improved Note Saving**:  
   - Resolved issues where formatting and links were not saved correctly in notes.  
   - Ensured notes with empty content cannot be saved.

7. **Export/Import and Clear Notes**:  
   - Added options to **export notes** as a backup, **import notes**, or **clear all notes** from the settings.

8. **Enhanced Cross-Browser Functionality**:  
   - Fixed compatibility issues with Edge browsers, ensuring smooth operation across platforms.

9. **Performance Optimization**:  
   - Improved loading times for the main interface, overlay, and expanded note view.

10. **Bug Fixes**:  
    - Fixed several bugs, including:  
      - Preventing multiple expanded windows from opening simultaneously.  
      - Correctly resizing the expanded window's text area when maximized.  
      - Ensuring expanded windows close when the extension or overlay is closed.

---

## Installation

You can easily install the Simple Note Saver Extension from the [Microsoft Edge Add-ons Store](https://microsoftedge.microsoft.com/addons/detail/mmlbgcfbfjnfneohfhenhbfhiihnomip).
